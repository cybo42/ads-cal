# ADS Planner

A Kotlin Multiplatform (Android + iOS, Compose Multiplatform) companion app for planning a visit to Android Dev Summit. It shows the agenda day by day, flags overlapping sessions, lets you favorite sessions and get reminders before they start, and can optionally sync your plan across devices (Firebase Auth + Firestore).

See the [Product Requirements Document](docs/PRD.md) for requirements, architecture, and the workstream breakdown.
